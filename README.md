# Flotation Digital Technologist

GUI-приложение на PyQt5 для прогнозирования параметров процесса флотации, загрузки технологических данных и подготовки моделей машинного обучения.

## Возможности

- прогнозирование результата по технологическим параметрам;
- загрузка Excel и CSV файлов;
- выбор целевой переменной;
- выбор параметров прогнозирования;
- предварительный просмотр таблицы;
- история расчётов;
- экспорт истории в CSV;
- подготовка данных для обучения модели;
- базовая оптимизация параметров.

## Технологии

- Python 3
- PyQt5
- pandas
- numpy
- scikit-learn
- openpyxl
